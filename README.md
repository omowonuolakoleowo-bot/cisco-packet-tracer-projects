# Wired LAN Design and Configuration

## Project Overview

This project demonstrates the design and configuration of a basic wired Local Area Network (LAN) using Cisco Packet Tracer.

## Network Topology

The network consists of 8 wired PCs, 2 switches, and 1 router. Four PCs are connected to each switch, while the router connects the two switches and allows communication between the network segments.

## Devices Used

- 8 Wired PCs
- 2 Switches
- 1 Router

## Connections

- Copper Straight-Through cables

## Connections

- The 8 PCs were connected to the switches using Copper Straight-Through cables.
- The switches were connected to the router using Copper Straight-Through cables.

## Configuration

The network was configured to allow communication between the connected devices.

- IP addresses were assigned to the PCs and router interfaces.
- 4 PCs were connected to each switch.
- Copper Straight-Through cables were used to connect the PCs to the switches.
- Copper Straight-Through cables were also used to connect the switches to the router.
- The router was configured to provide connectivity between the two network segments.
- The PCs were configured with the appropriate network settings.
- Connectivity was tested using the `ping` command.
- Successful ping tests were used to verify network communication.
- The topology was designed and tested using Cisco Packet Tracer.

- The topology was designed and tested using Cisco Packet Tracer.

## Results

The network was successfully configured and tested. The connected PCs were able to communicate across the network, and successful ping tests confirmed connectivity between the devices.
